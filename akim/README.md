# AqmolaCouncil — городской проектный офис

Основной модуль — паспорт одного городского проекта: сумма в тенге, проблема, направление, район, объём пилота, KPI и срок. На этих данных продукт готовит пошаговый план, шаблон распределения бюджета, возможный стек, план измерения и риски. Второй модуль сохраняет симулятор фиксированного городского бюджета из хакатонного ТЗ.

## Быстрый запуск

В корневой папке репозитория запустите `Start-AKIM.bat`. Нужен Node.js 22.13 или новее. Если зависимости уже установлены, дополнительных API-ключей или npm-команд не требуется; при первой установке пакетов нужны npm и интернет.

Ручной запуск из этой папки:

```powershell
node scripts/run-framework.mjs dev
```

Откройте адрес, который напечатает сервер; стандартный адрес — `http://localhost:5173`.

## Модули

- `/` — рабочее место акима: проектный паспорт в тенге, 5 направлений, план этапов, технологии и KPI.
- `/simulator` — фиксированные 100 виртуальных единиц, выбор ровно пяти мер, 14 инициатив и объяснение Astana Quality of Life Score.
- Проекты сохраняются в локальном хранилище браузера, последний сохранённый паспорт открывается после перезагрузки. JSON экспортирует структуру паспорта; PDF использует печать браузера.

## Архитектура и ограничения

`lib/akim/project-planner.ts` — детерминированные проверки, распределение введённой суммы с сохранением точного итога, горизонт этапов и локальные ответы по паспорту. Он не вызывает LLM и не отправляет введённые данные во внешние сервисы. Пять направлений содержат профили решения, техподходы, риски, базовые измерения и условия go/no-go.

`lib/akim/qol.ts` — отдельный движок фиксированного симулятора. Его данные и расчётный Astana Quality of Life Score учебные и синтетические.

Шаблон бюджетных долей 10/15/40/10/20/5% — не смета и не норматив. Демо-KPI не являются городскими данными. Приложение не прогнозирует эффект, не подключено к городским реестрам и не заменяет коммерческую смету, проверку ИБ, закупочную или отраслевую экспертизу.
